Core design direction

Design an elegant, editorial, luxury wedding-venue website that feels like a premium invitation card blended with a modern hospitality website. The experience should be warm, romantic, refined, memorable, and highly conversion-focused.

Use a new visual system:

•
Replace the previous plain stacked-card design with an editorial composition using asymmetrical layouts, overlapping image frames, decorative borders, large typography, vertical labels, and generous whitespace.

•
Use a cinematic hero with an offset text panel instead of centered hero text.

•
Use alternating full-bleed cream and ivory sections with occasional deep maroon panels.

•
Use image collages, framed photography, subtle paper texture, thin ornamental rules, and small gold accents.

•
Use elegant scroll-reveal animations, parallax image movement, and gentle hover transitions, but keep the experience fast and tasteful.

•
Do not use a generic SaaS template, neon colors, excessive glassmorphism, cartoon illustrations, or dense dashboards.
